# 历史文字模拟器

> 项目仓库：https://github.com/juntianguangyue/lishi-wenzi-moniqi.git

一个以「历史推演」为核心的中文文字模拟游戏。第一个可玩剧本为 **《崇祯十七年 · 甲申国难》**，你将扮演明思宗朱由检，从崇祯十七年正月初一开始，在闯军东征、清军窥关、朝臣党争与府库空虚之间，为大明作出每一个决定。

## 运行方法

本游戏为纯静态网页，无需安装任何环境：

1. 进入 `历史文字模拟器` 文件夹；
2. 用浏览器打开 `index.html`（推荐 Chrome / Edge / Firefox）；
3. 点击剧本卡片上的「开始游戏」。

也可以用任意静态服务器，例如：

```bash
cd 历史文字模拟器
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

### 手机版 / PWA

`index.html` 已做手机端适配，并附带 PWA 文件（`manifest.json`、`sw.js`、`icon-192.png`、`icon-512.png`）：

- Android Chrome：打开网页后，菜单中选「添加到主屏幕」；
- iPhone Safari：点分享按钮，选「添加到主屏幕」；
- 微信内可直接打开链接游玩，也可点右上角「···」在浏览器中打开后添加到桌面；
- 添加到主屏幕后，可全屏运行，体验接近 App。

### 关于微信小游戏

微信小游戏与普通网页不同：它不使用 DOM，需要 Canvas 重写界面，并需注册小游戏账号、AppID，使用微信开发者工具上传。本仓库当前是“手机网页版 + PWA”，可作为微信小游戏的前身版本；`data.js` 中的 140 个事件、506 个选项可原样复用到 Canvas 版。

## 已实现内容

- **140 个事件**，每个事件提供 3–4 个选项；
- 事件按历史时间线排序，选择后自动推进日期；
- **臣子奏疏引入事件**：李明睿、李邦华、倪元璐、吴襄、唐通、周遇吉、王承恩、史可法等会以上疏、密奏、塘报的方式引出事件；你是否信任他，将打开不同的事件链（如李明睿密备海舟、倪元璐清核京营、吴三桂先发精骑、唐通守居庸、周遇吉救援宁武、史可法江防三策等）；
- **崇祯心语旁白**：关键事件配有“崇祯心语”，呈现其犹豫、多疑、焦灼与自省；
- **506 个选项全部配承接句**：每次选择后，转场会先显示“你的选择如何落地”的承接句，再显示史籍原文；下一事件开头也有“前情承接”栏，把上下事件串起来；
- **史籍转场**：日期推进时插入《明史》《明季北略》《国榷》《甲申传信录》《明季南略》、吴伟业《圆圆曲》等原文；笔记逐字呈现，完整后停住，点击任意处继续，也可提前点击跳过；
- **人声朗读与设置**：奏疏原文、史籍转场笔记、崇祯心语可用浏览器语音朗读；设置中可开关声音，并在老者、中年文人、武将、女子、史官旁白之间切换音色，调整语速与音量；
- **存档与退出**：快速存档、存档并退出、主菜单继续未竟之局、重开本局；
- 多分支历史推演，包括：
  - 史实线：拒绝南迁、调不动勤王军、城破殉国；
  - 南迁线：崇祯亲赴南京，另立南都朝廷，直至扬州、南京攻防；
  - 太子监国线：太子南下，崇祯死国；
  - 吴三桂入援线：关宁军及时入关后的推演；
  - 周遇吉救援线：若救援得法，宁武关或可多撑，周遇吉退守居庸；
  - 御驾亲征线：崇祯轻出西征的冒险与败局；
  - 与李自成议和线：割西北、给犒军银的假设推演；
  - 城破逃亡线：只有预先备好海舟、密道，突围方有成功可能；
- 界面左上方常驻 **国库与收入** 面板：
  - 显示太仓、内帑、岁入应征与实征预估；
  - 点击可查看各省份/各项目的年额、状态与实征预估；
  - 太原、大同、山东、北直隶、南直隶等地失陷时，收入面板会相应变化；
- 界面左上方常驻 **军队** 面板：
  - 显示实存兵力、账面兵额、可战之兵、军心、将领数；
  - 点击可查看京营、勇卫营、关宁军、蓟镇、密云、昌平、宣大、山西、左良玉、黄得功、高杰、刘良佐、刘泽清、登莱水师等部的账面与实存兵力、主将、驻地、忠诚与士气；
- 民心、朝臣支持、军心、君威四维数值系统。

## 财政与军队数字说明

游戏中的“岁入应征”约 1365 万两，是把明末田赋折银、起运存留、辽饷·剿饷·练饷三饷加派与盐课、关税、内帑项目合并后的账面估计，参考黄仁宇《十六世纪明代中国之财政与税收》、顾诚《明末农民战争史》等研究。崇祯十七年初太仓存银设为 40 万两（今人考订约数十万两），内帑设为 100 万两（实数无确载，今人估计约百万两）。军队分“账面兵额”与“实存兵力”，京营、左良玉等部账面与实数相差极大，实存参考各家考订作近似处理。

## 事件数据说明

`data.js` 中的事件格式已注明字段含义。事件日期采用「崇祯十七年农历 + 公元纪年」近似换算，用于排序与天数推进；重要史事尽量依据《明史·庄烈帝纪》《明季北略》《甲申传信录》《流寇志》等记载，涉及假设分支的地方均在事件或结局中标注「推演」或「史实对照」。

## 主要史实节点

- 崇祯十七年正月初一，李自成在西安建国大顺，改元永昌；同日北京大风霾；
- 正月至二月，李邦华、李明睿等议南迁、太子监国，崇祯犹豫不决；
- 正月，大学士李建泰自请督师，崇祯亲送正阳门，李建泰逗留不进；
- 二月，李自成渡河入晋，太原失守，蔡懋德死节；
- 二三月间，周遇吉死守宁武关，城破殉国；
- 三月，姜瓖献大同，王承胤降宣府，唐通、杜之秩失居庸关；
- 三月十七日，李自成攻北京；十八日，杜勋入城议和；当夜外城开，十九日崇祯自缢煤山，王承恩从死；
- 此后，吴三桂引清军入关，南明弘光政权在南京建立，史可法督师扬州。
